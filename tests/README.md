# Eucalyn Trainer テスト

`test-runner.html` は、実際の `../index.html` を iframe に読み込み、画面操作と表示結果を検証する依存ライブラリ不要のブラウザーテストです。

> **公開時点のメモ:** 同梱の `index.html` は Broadsheet ベースの UI に更新されています。`test-runner.html` が参照する DOM（`#mainKeys` など）とは一致しないため、現状は自動テストが通りません。UI 改修に合わせた test-runner の更新は別途必要です。`index.html` 自体の動作はブラウザで確認してください。

## テストケース

1. テンキーレス表示と文字キー5段の構成
2. Windows／Macの自動判定・切替・保存
3. OSショートカットの保護
4. 初期状態のスペースキー・両親指ガイド
5. キー探索コースの開始と運指
6. 初心者コースでのWPM非表示・反復回数表示
7. 3回連続成功による完了
8. 誤入力による連続成功回数のリセット
9. 短いワードへの手動切替と反復
10. 例文コースの入力進行・誤入力判定
11. やり直しと次課題への切替
12. 例文の全文完了と次課題開始
13. 「今日の5分」セッションの開始
14. 経過時間による課題区間と振り返りの自動切替
15. 5分終了と任意延長
16. 中断後の安全な待機状態への復帰
17. 習得条件によるおすすめ段階の更新
18. 入力履歴・混同キーの端末内保存と再読み込み
19. 反応時間と2文字連鎖の弱点分析
20. 弱点60%・現在25%・復習15%の適応メニュー
21. 5分セッション結果の保存
22. ガイドの自動・常時・非表示設定と保存
23. 習得後のガイド非表示と、再失敗時の自動復帰
24. 進捗画面の習得数・弱点数・自己ベスト・次の小目標
25. 5分完了時の事実に基づく成長メッセージ
26. 進捗JSONの保存・削除・復元
27. 不正な進捗JSONの拒否と既存データ保護
28. 実務練習の手動選択・実務文・WPM表示
29. 15 WPM・正確率95%による最低限の実務目安判定
30. 3回の基準達成による実務練習への段階進行
31. 実務向け5分セッションの区間切替
32. 到達メッセージと、到達状態を取り消さない判定

## 実行方法

プロジェクトのルートでローカルHTTPサーバーを起動し、`/tests/test-runner.html` をブラウザーで開きます。ローカルファイルとして直接開くと、ブラウザーの同一生成元制限によりテスト対象を読み取れない場合があります。

例：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:4173/tests/test-runner.html` を開くと、36件の結果が自動表示されます。
